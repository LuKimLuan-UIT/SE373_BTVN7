Usage, context và compact

Offline không khởi tạo/gọi LLM. Compact trích dẫn theo marker và schema; đếm log bằng runtime. Chỉ hỗ trợ các kịch bản đã công bố, không giả làm suy luận LLM. Provider là lựa chọn riêng, dùng cấu hình .env và có thể phát sinh usage.

Usage cộng input/output token do provider báo của mọi lượt gọi trong phiên, kể cả tool rounds và lượt compact. Đây không phải hạn mức tài khoản. Thiếu usage sẽ hiện “không đủ usage”, không thay bằng 0.

Context ước lượng input của lượt kế bằng JSON UTF-8 bytes/4, gồm active messages, instructions và tool schemas; chưa gồm tin nhắn bạn đang gõ. Không phải token count chính xác của model.

Cảnh báo từ 80% ngưỡng, không tự khẳng định model đã đầy context và không tự chặn gửi tin nhắn.

Compact giữ user/system instructions và kế hoạch AI gần nhất nếu ≤2.000 ký tự, không có tool calls. Model tạo checkpoint có schema; archive gốc được giữ riêng. Checkpoint vẫn có thể sai, có thể mở để kiểm tra. Sliding window đơn thuần dễ làm mất constraint cũ; summary tự do khó kiểm tra đủ trường. Compact phát sinh thêm một lượt model.

Code Mode xử lý log trong runtime, chỉ trả findings giới hạn. Ba API read_logs/select/summarize; không Python tùy ý. Giới hạn 100 file, 8 MiB, 50.000 records, output 12.000 bytes; không phải OS sandbox.
